TTL进入failsafe模式：
按住[f]键并不断按[enter]进入failsafe模式
输入命令修改root账号密码为password，然后reboot重启
echo -e 'password\npassword' | passwd root
reboot

系统启动后按回车，TTL登录root账号，设置dropbear开启并重启dropbear服务：
uci set dropbear.@dropbear[0].enable='1'
uci commit dropbear
/etc/init.d/dropbear start

uboot的使用：
网线插入LAN1-5中的一个口，电脑设置IP 192.168.1.2/24，按住reset键上电路由器，等待SYS灯由闪烁变为常亮即可松开reset键。浏览器打开192.168.1.1刷固件，等待界面显示complete即成功刷写。

## 【【【切换21.02固件和23.05/master固件】】
## 当前在23.05/master固件，要切换到21.02固件
## 如下下面命令修改环境变量，没有报错即可，然后reboot重启
cp /etc/fw_env.config /etc/fw_env.config.bak
echo -e "/dev/mmcblk0p1 0 0x80000" > /etc/fw_env.config
fw_setenv dual_boot.current_slot 0 ##设置启动21.02的bin固件
cp /etc/fw_env.config.bak /etc/fw_env.config

## 当前在21.02固件，要切换到23.05/master固件
## 如下下面命令修改环境变量，没有报错即可，然后reboot重启
fw_setenv dual_boot.current_slot 1 ##设置启动23.05、master的itb固件
